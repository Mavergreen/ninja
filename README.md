# ninja for Mavericks

**This README has not been read or edited by a human yet.** Until it has, this project cannot cut
its first release.

The ninja build system for Mac OS X 10.9 Mavericks, and Apple Silicon Macs that build for it: an
unofficial community build, not affiliated with the ninja project. Installs
`/usr/local/mavergreen/ninja/bin/ninja`, linked as `/usr/local/mavergreen/bin/ninja`.

ninja itself (https://ninja-build.org, https://github.com/ninja-build/ninja) is by its authors, under the
Apache License 2.0; its `COPYING` is installed at `/usr/local/mavergreen/ninja/share/doc/ninja/COPYING`.
